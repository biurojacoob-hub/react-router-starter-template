# Content Structure — Family Finance Academy

> Kompletna architektura treści edukacyjnych: poziomy wiekowe, kursy, moduły, lekcje i quizy.

---

## 1. Model poziomów wiekowych

Treści są dynamicznie dostosowywane do wieku dziecka. System operuje na czterech ścieżkach wiekowych z wspólnym fundamentem programowym.

```
┌─────────────────────────────────────────────────────────────────┐
│                    ŚCIEŻKI WIEKOWE                               │
├─────────────┬──────────────┬─────────────────┬─────────────────┤
│  EXPLORER   │   LEARNER    │   ACHIEVER      │   MASTER        │
│  6–8 lat    │   9–11 lat   │   12–14 lat     │   15–18 lat     │
├─────────────┼──────────────┼─────────────────┼─────────────────┤
│ Pojęcia     │ Mechanizmy   │ Strategie       │ Zaawansowane    │
│ podstawowe  │ pieniądza    │ finansowe       │ narzędzia       │
│             │              │                 │                 │
│ Monety,     │ Budżet,      │ Oszczędzanie,   │ Inwestowanie,   │
│ banknoty,   │ oszczędzanie,│ inwestowanie,   │ podatki,        │
│ kupowanie   │ zarabianie   │ kredyt, procent │ FIRE, ETF, IKE  │
└─────────────┴──────────────┴─────────────────┴─────────────────┘
```

### Adaptacja treści według wieku

| Element | 6–8 lat | 9–11 lat | 12–14 lat | 15–18 lat |
|---|---|---|---|---|
| Długość lekcji | 5–8 min. | 8–12 min. | 12–18 min. | 15–25 min. |
| Proporcja animacji | 70% | 50% | 30% | 15% |
| Pytania quizowe | 3 | 5 | 7 | 10 |
| Abstrakcja | Niska | Średnia | Wysoka | Ekspercka |
| Słownictwo | Proste | Rozbudowane | Branżowe | Dorosłe |
| Przykłady | Zabawki, słodycze | Gry, gadżety | Wakacje, laptop | Samochód, mieszkanie |

## 3. Struktura lekcji (szablon)

Każda lekcja składa się z modułów treści ułożonych w sekwencji:

```
LEKCJA (szablon)
│
├── 1. HOOK (30 sek.)
│      "Czy wiesz, że..." / pytanie otwierające / historia
│
├── 2. TREŚĆ GŁÓWNA (40–60% czasu)
│      • Slajdy tekstowo-graficzne (max 80 słów / slajd)
│      • Animacje / wideo (max 90 sek. per segment)
│      • Infografiki i diagramy
│
├── 3. ELEMENT INTERAKTYWNY (20–25% czasu)
│      • Sortowanie / drag-and-drop
│      • Kalkulator / symulacja
│      • Scenariusz decyzyjny
│      • Mini-gra
│
├── 4. QUIZ (15–20% czasu)
│      • 3–10 pytań (zależnie od wieku)
│      • Single choice / multi-choice / true-false
│      • Immediate feedback z wyjaśnieniem
│
└── 5. PODSUMOWANIE + NAGRODA
       • Kluczowe wnioski (3 punkty)
       • XP + animacja
       • "Misja dnia" powiązana z lekcją
       • "Zapytaj AI Mentora..." (prompt suggestion)
```

## 4. System quizów

### Typy pytań

| Typ | Opis | Użycie |
|---|---|---|
| **Single choice** | 1 poprawna z 4 opcji | 60% pytań |
| **Multi-select** | Kilka poprawnych | 15% pytań |
| **True/False** | Prawda/Fałsz z uzasadnieniem | 10% pytań |
| **Drag & Drop** | Sortowanie do kategorii | 10% pytań |
| **Obliczeniowe** | Wypełnij wynik | 5% pytań |

### Zasady quizów

- Minimum 60% poprawnych → zaliczenie lekcji
- Błędna odpowiedź → natychmiastowe wyjaśnienie → ponowienie pytania
- Po 3 błędach → "Tryb nauki" (podpowiedź + uproszczone wyjaśnienie)
- Wynik 100% → bonus +25% XP ("Perfect Score")
- Quiz finalny kursu: 80% poprawnych → certyfikat kursu

### Baza pytań

- Każda lekcja: min. 15 pytań w bazie (rotacja)
- Repeat lekcji: losowanie innego zestawu (max 70% pytań tych samych)
- AI generuje nowe pytania co miesiąc na podstawie treści lekcji
